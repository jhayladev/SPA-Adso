1. Variables globales

$catalogo = [ ... ];
$diasValidos = ['lunes', 'martes', ...];
$empleados = [];
$citas = [];
$datosCargados = false;
Lógica: estos 5 arreglos/variables viven "afuera" de todas las funciones, en el nivel principal del script. Son los datos que el programa va a manipular durante toda su ejecución: el catálogo de servicios es fijo, y $empleados/$citas empiezan vacíos y se van llenando con lo que el usuario registre. $datosCargados es una bandera (true/false) para saber si ya se usó la opción "dp".
Raro — por qué las funciones NO ven estas variables solas: en PHP, una variable creada afuera de una función (global) no es visible automáticamente adentro de una función. Por eso cada función como registrarEmpleado($empleados) recibe $empleados como parámetro: es la forma de "pasarle" el dato. Vas a ver esto en casi todas las funciones del archivo.

2. Funciones de lectura y validación

leer($mensaje)

function leer($mensaje) {
    return trim(readline($mensaje));
}
readline($mensaje): muestra el mensaje en pantalla y espera a que el usuario escriba algo y presione Enter. Es el "input" de PHP en consola (equivalente a input() en Python). Devuelve exactamente lo que el usuario escribió, como texto.
trim(texto): quita espacios en blanco sobrantes al inicio y al final del texto. Ejemplo: trim(" hola ") devuelve "hola". Se usa porque si el usuario escribe un espacio de más sin querer, no queremos que cuente como un dato distinto.
Esta función leer() es la base: todas las demás funciones de lectura la usan por dentro para no repetir trim(readline(...)) cien veces.

leerTextoNoVacio($mensaje)

function leerTextoNoVacio($mensaje) {
    do {
        $valor = leer($mensaje);
        if ($valor === '') {
            echo "Este campo no puede quedar vacío.\n";
        }
    } while ($valor === '');
    return $valor;
}
Lógica: un do...while siempre ejecuta el bloque al menos una vez, y luego repite mientras la condición sea verdadera. Aquí: pide el dato, si vino vacío ('') avisa y vuelve a preguntar; si no está vacío, sale del ciclo y devuelve el valor. Es el patrón que vas a ver una y otra vez: "pedir dato → validar → si está mal, repetir".

leerDia($mensaje, $diasValidos)

function leerDia($mensaje, $diasValidos) {
    do {
        $dia = strtolower(leer($mensaje));
        $valido = in_array($dia, $diasValidos, true);
        if (!$valido) {
            $listaDias = "";
            for ($i = 0; $i < count($diasValidos); $i++) {
                if ($i > 0) {
                    $listaDias = $listaDias . ", ";
                }
                $listaDias = $listaDias . $diasValidos[$i];
            }
            echo "Día inválido. Use uno de: " . $listaDias . "\n";
        }
    } while (!$valido);
    return $dia;
}
strtolower(texto): convierte todo el texto a minúsculas. Ejemplo: strtolower("LUNES") devuelve "lunes". Se usa para que no importe si el usuario escribió "Lunes", "LUNES" o "lunes" — todo se compara en minúsculas contra $diasValidos, que también está en minúsculas.
in_array($valor, $arreglo, true): revisa si $valor existe adentro de $arreglo y devuelve true/false. El tercer parámetro true le dice a PHP que compare también el tipo de dato (no solo el valor) — es una buena costumbre para evitar comparaciones raras entre texto y número.
La lista de días separada por coma ya no usa una función aparte: el for recorre $diasValidos y va pegando cada palabra al texto $listaDias, agregando ", " antes de cada una menos la primera (por eso el if ($i > 0)).

leerHora($mensaje)

function leerHora($mensaje) {
    do {
        $hora = leer($mensaje);
        $valido = ctype_digit($hora) && (int)$hora >= 8 && (int)$hora <= 18;
        if (!$valido) {
            echo "La hora debe ser un número entre 8 y 18.\n";
        }
    } while (!$valido);
    return (int)$hora;
}
ctype_digit($hora): revisa si el texto contiene solo dígitos (0-9), sin letras ni signos. Es necesario porque leer() siempre devuelve texto (string), y antes de convertirlo a número queremos estar seguros de que el usuario no escribió "ocho" o "8a". Si ctype_digit fuera falso y de todas formas hiciéramos (int)$hora, PHP no daría error pero podría convertir cosas raras a 0.
(int)$hora: esto es un "cast" — convierte el texto a número entero. leer() siempre te da texto, aunque el usuario haya escrito solo números; con (int) lo pasamos a número de verdad para poder comparar >= 8 y <= 18.

leerNumeroEnLista($mensaje, $totalItems)

Misma idea que leerHora, pero el rango válido es 1 hasta $totalItems (por ejemplo, la cantidad de empleados o de servicios disponibles). Se usa para que el usuario elija "el número 3 de la lista" en vez de escribir el nombre completo.

3. formatearDinero($valor)

function formatearDinero($valor) {
    return "$" . number_format($valor, 0, ',', '.');
}
number_format($valor, 0, ',', '.'): convierte un número a texto con separador de miles. Los 4 parámetros son: el número, cuántos decimales mostrar (0 = ninguno), qué símbolo usar para separar decimales (no aplica acá) y qué símbolo usar para separar miles (., como se escribe en Colombia). Ejemplo: number_format(80000, 0, ',', '.') devuelve "80.000". Luego se le pega el "$" adelante con el . (punto), que en PHP es el operador para unir/concatenar dos textos.

4. Funciones propias de formato de texto

function espacioDerecha($texto, $ancho) {
    $texto = (string) $texto;
    while (strlen($texto) < $ancho) {
        $texto = $texto . " ";
    }
    return $texto;
}

function espacioIzquierda($texto, $ancho) {
    $texto = (string) $texto;
    while (strlen($texto) < $ancho) {
        $texto = " " . $texto;
    }
    return $texto;
}

function linea_repetida($caracter, $cantidad) {
    $linea = "";
    for ($i = 0; $i < $cantidad; $i++) {
        $linea = $linea . $caracter;
    }
    return $linea;
}
Para qué sirven: son las funciones que arman las "columnas" alineadas de las tablas que se ven en consola. La idea es simple: si un texto mide menos que el ancho que queremos, le vamos pegando espacios hasta llegar a ese ancho.
  • espacioDerecha("Ana", 6) → "Ana " (el espacio queda a la derecha, por eso el texto queda "pegado a la izquierda" al imprimirlo — se usa para nombres).
  • espacioIzquierda("500", 6) → " 500" (el espacio queda a la izquierda, el texto queda "pegado a la derecha" — se usa para números, para que las cifras se alineen por la derecha como en Excel).
strlen($texto): devuelve cuántos caracteres tiene un texto. strlen("Ana") es 3. El while compara ese número contra el ancho deseado y sigue agregando espacios mientras sea menor.
(string) $texto: otro "cast", como (int) pero al revés — convierte lo que sea (un número, por ejemplo) a texto. Es necesario porque a veces le pasamos un número a estas funciones (como $numCitas[$i]) y strlen() necesita trabajar con texto, no con número.

5. Funciones de cálculo: duracionCita, horaFinCita, totalCita

function duracionCita($cita, $catalogo) {
    $total = 0;
    foreach ($cita['servicios'] as $idServicio) {
        $total += $catalogo[$idServicio]['duracion'];
    }
    return $total;
}
$cita['servicios'] es un arreglo de números (los índices de $catalogo), por ejemplo [0, 3] significa "Limpieza facial + Masaje relajante". El foreach recorre esos índices uno por uno y con cada uno busca en $catalogo la duración de ese servicio, sumándola a $total. totalCita hace exactamente lo mismo pero sumando precio en vez de duracion. horaFinCita simplemente le suma la duración total a la hora de inicio.
$total += $catalogo[...]: es lo mismo que escribir $total = $total + $catalogo[...], es solo una forma corta de escribirlo.

6. registrarEmpleado y registrarCita

function registrarEmpleado(&$empleados) {
    do {
        ...
        $empleados[] = ['nombre' => $nombre, 'especialidad' => $especialidad];
        ...
    } while ($otro === 's');
}
&$empleados (el símbolo &): esto se llama "paso por referencia". Normalmente cuando le pasas un arreglo a una función, PHP hace una copia — si la función lo modifica, el original afuera no cambia. Con & le decimos a PHP "no copies, trabaja directo sobre el arreglo original". Por eso cuando registrarEmpleado hace $empleados[] = [...], el $empleados que está afuera (la variable global) sí queda con el nuevo empleado adentro. Fíjate que cuando se llama a la función (registrarEmpleado($empleados); en el menú) no se escribe el & — el & solo va en la definición de la función.
$empleados[] = [...]: los corchetes vacíos [] agregan un elemento nuevo al final del arreglo (como .append() en Python o .push() en JavaScript).
registrarCita usa la misma idea de referencia (&$citas) y además tiene un segundo do...while adentro para permitir agregar varios servicios a la misma cita (uno, o dos, o los que el usuario quiera) antes de guardar la cita completa.
empty($empleados): devuelve true si el arreglo está vacío (no tiene ningún elemento). Se usa al inicio de registrarCita para no dejar agendar una cita si todavía no hay ningún empleado registrado.

7. totalFacturadoPorEmpleado

$totales = [];
for ($i = 0; $i < count($empleados); $i++) {
    $totales[] = 0;
}

foreach ($citas as $cita) {
    $idEmp = $cita['empleado'];
    $totales[$idEmp] = $totales[$idEmp] + totalCita($cita, $catalogo);
}
Paso 1 — crear el arreglo de totales en cero: se crea un arreglo $totales con un 0 por cada empleado (si hay 4 empleados, queda [0, 0, 0, 0]). La posición $totales[2] va a representar "lo que lleva facturado el empleado con índice 2".
Paso 2 — sumar: se recorre cada cita, se mira a qué empleado pertenece ($cita['empleado'] es un número, el índice) y se le suma el total de esa cita a su posición correspondiente en $totales. 
for ($i = 0; $i < count($filas); $i++) {
    for ($j = 0; $j < count($filas) - 1 - $i; $j++) {
        if ($filas[$j]['total'] < $filas[$j + 1]['total']) {
            $temp = $filas[$j];
            $filas[$j] = $filas[$j + 1];
            $filas[$j + 1] = $temp;
        }
    }
}
Esto es "ordenamiento burbuja" (bubble sort): es la forma más simple de ordenar un arreglo sin usar funciones especiales. La idea: comparamos cada elemento con el de al lado; si el de la izquierda es menor que el de la derecha (y queremos de mayor a menor), los intercambiamos. Repetimos esto varias veces (el for de afuera) hasta que todo quede en orden — en cada "pasada" el elemento más grande "burbujea" hacia el principio. El $temp es una variable temporal necesaria para intercambiar dos valores: si no la usaras, al hacer $filas[$j] = $filas[$j+1] perderías el valor original de $filas[$j] antes de poder guardarlo en $filas[$j+1].

8. servicioMasSolicitado

Misma idea que la función anterior para crear $conteo y $facturado en cero, uno por cada servicio del catálogo. Por cada cita, recorre sus servicios y va sumando 1 al contador y el precio al facturado, en la posición de ese servicio. 
$idGanador = 0;
for ($i = 1; $i < count($conteo); $i++) {
    if ($conteo[$i] > $conteo[$idGanador]) {
        $idGanador = $i;
    }
}
Buscar el máximo a mano: arrancamos suponiendo que el ganador es el primero (índice 0). Luego recorremos el resto (por eso $i arranca en 1, no en 0) y cada vez que encontramos uno con más conteo que el ganador actual, actualizamos $idGanador. Al terminar el for, $idGanador tiene el índice del servicio más pedido. La misma técnica se repite en liquidacionComisiones para encontrar el $maxTotal.

9. agendaDeUnDia

$citasDelDia = [];
foreach ($citas as $cita) {
    if ($cita['dia'] === $dia) {
        $citasDelDia[] = $cita;
    }
}
Filtrar a mano: se crea un arreglo vacío y se recorren todas las citas; solo las que coinciden con el día pedido se agregan al arreglo nuevo. Después se ordena por hora con el mismo bubble sort que ya viste (comparando ['hora'] en vez de ['total']). 
$textoServicios = "";
for ($i = 0; $i < count($cita['servicios']); $i++) {
    if ($i > 0) {
        $textoServicios = $textoServicios . ", ";
    }
    $idServicio = $cita['servicios'][$i];
    $textoServicios = $textoServicios . $catalogo[$idServicio]['nombre'];
}
Esta parte arma el texto "Manicure, Pedicure" a mano: empieza con texto vacío y por cada servicio de la cita le va pegando el nombre, agregando ", " antes de cada uno menos el primero — el mismo patrón que ya usaste para la lista de días válidos.

10. deteccionConflictos

for ($i = 0; $i < $total; $i++) {
    for ($j = $i + 1; $j < $total; $j++) {
        ...
        if ($inicioA < $finB && $inicioB < $finA) {
            $encontrados = true;
            ...
        }
    }
}
Por qué dos ciclos anidados: para saber si hay conflicto, hay que comparar cada cita contra todas las demás. El ciclo de afuera toma una cita ($i), el de adentro toma otra cita después de esa (por eso $j arranca en $i + 1, así nunca compara una cita consigo misma ni repite la misma pareja dos veces). Si ambas citas son del mismo empleado, mismo día, y sus horarios se cruzan ($inicioA < $finB && $inicioB < $finA — la condición clásica para saber si dos rangos de horas se superponen), se marca como conflicto.

11. liquidacionComisiones

if ($numCitas[$i] >= 6) {
    $porcentaje = 0.12;
    $porcentajeTexto = "12";
} else {
    $porcentaje = 0.08;
    $porcentajeTexto = "8";
}
Por qué hay dos variables (número Y texto) para el mismo porcentaje: en PHP (y en casi todos los lenguajes), los números decimales no siempre son exactos. Si calculas 0.12 * 100 para mostrar "12%", a veces el resultado real es 11.999999999999998 en vez de 12 — por eso el código original usaba round() (redondear) para "arreglar" ese error minúsculo antes de mostrarlo. Acá evitamos el problema de raíz: en vez de calcular el porcentaje como texto, simplemente lo escribimos directo ("12" o "8"), y usamos el número decimal (0.12/0.08) solo para la cuenta real de la comisión ($totales[$i] * $porcentaje), donde ese pequeño error de decimales no afecta nada porque no se está mostrando en pantalla.

13. mostrarMenu y pausar

function mostrarMenu() {
    static $primeraVez = true;

    if ($primeraVez) {
        $primeraVez = false;
    } else {
        sleep(1);
    }
    system('clear');
    ...
}
static $primeraVez: una variable normal dentro de una función "olvida" su valor cada vez que la función termina. static hace que la variable recuerde su valor de una llamada a la siguiente. Aquí sirve para saber si es la primera vez que se muestra el menú (no espera) o si ya se mostró antes (sí espera 1 segundo, para que el usuario alcance a leer el mensaje anterior antes de que la pantalla se borre).
sleep(1): pausa la ejecución del programa 1 segundo.
system('clear'): ejecuta el comando clear de la terminal, que borra todo lo que se ha impreso en pantalla — así el menú siempre aparece "limpio".

14. El bucle principal (while + switch)

$opcion = "";

while ($opcion !== "8") {
    mostrarMenu();
    $opcion = leer("Seleccione una opción: ");

    switch ($opcion) {
        case "1":
            ...
            break;
        ...
    }
}
El corazón del programa: mientras la opción elegida no sea "8" (salir), el while se repite: muestra el menú, lee qué eligió el usuario, y con switch decide qué función llamar según ese número. Cada case es una posible opción; break; es obligatorio al final de cada uno — sin él, PHP seguiría ejecutando el case siguiente aunque no corresponda (esto se llama "fall-through" y casi nunca es lo que uno quiere). El default atrapa cualquier cosa que el usuario escriba que no sea una opción válida.
